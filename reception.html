Calendario eventi

Aggiungi le date. Le prenotazioni aprono automaticamente 7 giorni prima. Il giorno dell'evento la tabella VTV passa da LOCATION a STATO, aggiornando ogni rituale per 10 minuti dalla partenza.

Programma rituali

Modifica il programma standard oppure scegli una data già creata. Ogni evento ha il suo programma, così puoi aggiungere o cambiare un rituale senza modificare gli altri eventi.

Cartello ufficiale marketing

Il cartello va mantenuto identico al file ricevuto dal marketing. Scegli una nuova immagine JPG o PNG: potrai scaricarla con il nome cartello.jpg e sostituire quella nel repository GitHub.

Se non selezioni un'immagine, GitHub continuerà a usare il cartello già pubblicato. Non viene applicata nessuna modifica grafica all'immagine selezionata: la conversione JPG è necessaria solo per uniformare il nome del file.

Pubblica modifiche su VTV

Non è necessario alcun database. Per mantenere le modifiche tra computer, esporta il file qui sotto e caricalo nel repository piovanim-art/rituali, sostituendo il precedente. La pagina VTV dovrà essere configurata per leggere eventi.json.

Passaggi: 1. Scarica eventi.json. 2. In GitHub apri il repository e usa Add file → Upload files per sostituirlo. 3. Se hai cambiato il cartello, carica anche cartello.jpg. 4. La pagina VTV leggerà i file aggiornati al successivo refresh.

Attenzione: il vecchio index.html deve essere adattato a questo nuovo formato. Il semplice caricamento dei file non attiva da solo la nuova schermata.
